# Experiment 001: Minimal Semantic HTML Baseline

## Goal and selected idea

Establish a reference for later native Web Platform experiments: one visible
Hello World heading in a standalone semantic HTML document, rendered entirely
with browser defaults. Acceptance requires successful real-Chromium verification,
a 1280 x 800 screenshot, and actual visual review before sealing.

Experiment 001 uses the specification's reference HTML. It is exempt from
three-candidate selection and historical novelty comparisons; adding styling or
interaction would undermine the reference.

## Technology and signatures

- Technology: HTML5 document, `main` landmark, `h1` heading, viewport metadata.
- Mechanism Signature: HTML main + h1 -> native document rendering -> Hello World.
- Design Signature: Typography: browser-default bold serif; Color: black on white;
  Composition: upper-left normal document flow; Material: unadorned document;
  Motion: static.

## Implementation and architecture

`001.html` is the eventual sealed standalone artifact. During development it is
`001.dev.html`. There are no authored styles, scripts, companion assets, fonts,
network calls, permissions, animations, or interaction controls. Its English
source comment explains why the baseline deliberately omits CSS and JavaScript.

The run's `tools.js` uses Node built-ins and installed Chromium through CDP.
Verification functions are reused directly rather than invoked through nested
CLI processes. Each verification owns an ephemeral loopback HTTP server and
temporary browser profile and removes both on completion. The public web server
defaults to `127.0.0.1:7373`, rejects traversal and escaping symlinks, and fails
explicitly on occupied ports.

## Verification evidence

`node tools.js verify 001/001.dev.html 001` returned exactly `OK` with exit code 0
using Chromium 153.0.8010.52 on Linux. `verification.json` records two observations:
one visible `h1` with text Hello World, no reported issues, no graphics, no
application animation callbacks, and no animations. The title is Hello World.
Dependency, doctype, duplicate-ID, permission, runtime, and visibility gates
passed. No console errors or unexpected runtime requests were reported.

Tooling was validated first with
temporary fixtures: 30 CLI checks passed, with additional assertions for PNG
dimensions, HTTP serving, encoded traversal, and symlink escape. A machine-readable
record is retained as `../tooling-validation.json`; the fixture code, HTML,
screenshots, and symlink are temporary and will be removed.

## Visual evidence and review

`screenshot.png` was generated by real Chromium at 1280 x 800 and opened with the
image-view tool after verification. Visual review confirmed identifiable bold
black serif Hello World text near the upper-left of the white document, consistent
with default heading margins. It is the only visual subject. No clipping,
overlap, missing glyphs, unrelated UI, or broken rendering was observed.

This experiment is static, so one primary screenshot is sufficient. There are no
prior sealed experiments in this fresh run to compare for visual repetition.

## Limitations

Browser-default font metrics may vary across operating systems and installed
fonts. The screenshot documents this installed Chromium environment rather than
asserting universal pixel identity. Automated visibility uses text bounds,
computed styles, composed ancestry, and hit-testing, not a proof of semantic
legibility; actual visual inspection supplies that check.

Tooling is not a universal formal validator. CSS checks use Chrome's parser and
inspector declaration metadata for DOM-matched rules; inactive or unmatched rules
are not exhaustively syntax-validated. Static dependency checks conservatively
reject network-capable constructs, including safe uses that cannot be established
by the scanner. Runtime interception independently rejects unexpected requests.
Future graphical, dynamic, or interactive experiments require measured
technology-specific contracts and appropriate temporal or interaction captures;
this baseline does not demonstrate those technologies.

## Definition of Done

- Baseline HTML capability and both signatures recorded; Experiment 001's
  selection and novelty-comparison exceptions applied.
- Hello World is the sole conceptual and visual subject.
- English source explanation and self-contained report/journal are present.
- Zero runtime dependencies and no permission attempt passed automated gates.
- Verification returned `OK`; the required screenshot was opened and reviewed.
- No dynamic or interactive evidence requirement applies.
- Inventory, progress, and active state are updated before sealing.
- No baseline property needs an additional human check; tooling limitations are
  stated rather than represented as universally proven.
