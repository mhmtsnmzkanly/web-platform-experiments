# 067 — Signed Ink

Goal: let actual byte authentication control greeting acceptance typography.
Candidates: HMAC ink; layered cascade; compact vertical type. Selected sign/verify,
unlike 021's unauthenticated digest-derived layout.
Mechanism Signature: signed bytes -> verification result -> accepted/cancelled ink.
Design Signature: serif/italic; green/red/cream; inscription; signed ink; rejection.
An ephemeral nonextractable key signs the original bytes. One flipped bit is
verified against that signature; unexpected acceptance throws. The visual subject
stays Hello World while the altered-byte edition is cancelled. Evidence requires
original true, tampered false and 32-byte signature. verify OK; both images opened:
green inscription becomes readable red italic cancellation with accurate status.
Limits: local integrity demo, not sender identity/security certification;
no key storage, network resources or permissions.
