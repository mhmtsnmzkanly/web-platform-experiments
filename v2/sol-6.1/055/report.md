# 055 — Shared Space

Goal: couple native weighted shrink to actual greeting word sizes.
Candidates: weighted flex type; binary tiles; local message routing. Selected
negative-free-space allocation, unlike 010's externally resized container.
Mechanism Signature: flex shrink weights -> allocated width -> cqw typography.
Design Signature: serif; orange/sage/charcoal; split surface; elastic paper; trade.
Two 600px bases share 1000px. Weights 1:3 yield 550/450; changing to 4:1 yields
440/560. Container units automatically resize glyphs. Exact box widths are tested.
verify OK: expected allocations within one pixel. Both images opened: split
boundary shifts and relative word sizes reverse, with intact readable text.
Limits: fixed desktop specimen, not responsive UI;
no external resources or permissions.
